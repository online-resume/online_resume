A multi-user web app that tailors a master resume to each job description using a chain of LLM agents, then automates the rest of the job search. Each edit is kept only if it passes rule checks and improves the local ATS score. The app also drafts and sends application emails, reads recruiter replies and tracks every application on a Kanban board. It also includes a Telegram bot for approving applications from a phone, a Chrome extension that captures job postings, an interview-prep generator, role-based permissions, and one model setting per agent with automatic fallback between API keys.

Outcome: Cut a tailored application from about 30-45 minutes of manual work to a single approval click, with resume, PDF and email all generated automatically. Brings in roles from 5 job sources and matches each one to the right profile, so the user no longer has to screen postings by hand. Coordinates 27 configurable AI agents, with fallback between API keys so jobs keep running when a key runs out of credits. Backed by 1,100+ unit tests that fake every external service, so testing never sends a real email or calls a paid API. About 87k lines of code (Python and JavaScript), and every page works on a phone.
